Adidas CLO Plugins

Architecting digital asset pipelines and high-performance DCC plugins for global design teams.

Jun 2021 - Dec 2022 Adidas (via 4D Pipeline) C++ Qt CLO-SDK AWS Serverless Python Unreal Engine 4

Consolidated Digital Asset Ecosystem

As the Main Developer for the Adidas CLO Plugin suite, I consolidated multiple legacy tools into a unified, high-performance asset library serving hundreds of global designers across their global “Digital Creation” hubs.

  • Ecosystem Consolidation: Enabled designers to seamlessly drag-and-drop assets directly within their 3D design environment, bypassing slow legacy applications and unblocking hundreds of users.
  • Scalable Cloud Architecture: Architected and migrated the asset database to an AWS Serverless backend, successfully supporting tens of thousands of digital garments.

UE4 Alembic Importer Plugin

Engineered a custom Alembic Importer for Unreal Engine 4 to bridge the gap between design and real-time visualization.

  • Drastic Pipeline Acceleration: Reduced material and texture assignment overhead from ~15 minutes per file down to a single click.
  • Batch Import Capabilities: Enabled high-fidelity, metadata-driven automated imports of entire garment collections.
  • Highly Extensible: Built to allow Adidas teams to override material and texture mapping rules on the fly.

Smartsheet Data Orchestration

Developed a specialized automation tool to interface with the Smartsheet API. The tool retrieves complex asset data for tens of thousands of items and converts it into structured CSV formats using custom JSON templates, enabling seamless synchronization between global project management and technical asset databases.

Adidas CLO Plugins

Developed through **4D Pipeline**, architecting digital asset pipelines and high-performance DCC plugins for global design teams.

Pipeline Engineering

CLO Asset Management Ecosystem

I developed and maintained a comprehensive CLO plugin suite that provides designers with seamless access to Adidas' vast digital asset library (fabrics, trims, colors, avatars, and logos). The project involved a full-stack architectural approach:

C++/Qt Plugin

A high-performance desktop library integrated directly into CLO for searching, sorting, and metadata interaction.

AWS Backend

Scalable serverless architecture utilizing Lambda, Step Functions, Event Bridge, and S3.

Data Services

Python-based microservices for database management and Smartsheet API synchronization.

Engine Tools

UE4 Alembic Importer Plugin

To bridge the gap between design and real-time visualization, I engineered a custom Alembic Importer for Unreal Engine 4. This tool automates the process of importing high-fidelity assets from CLO or Modo, including the intelligent assignment of materials and textures based on metadata—significantly reducing manual pipeline overhead for technical artists.

Automation

Smartsheet Data Orchestration

Developed a specialized automation tool to interface with the Smartsheet API. The tool retrieves complex asset data and converts it into structured CSV formats using custom JSON templates as blueprints, enabling seamless data flow between project management platforms and technical asset databases.
